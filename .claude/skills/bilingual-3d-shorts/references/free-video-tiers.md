# Free image-to-video options for hero shots (manual, $0)

Only for `nano` hero shots (code3d and faceless shots already move). Free allowances change often: the numbers below are
from Nov 2026 roundups, so check each tool's own page. Always use **image-to-video with the keyframe as the start frame**,
9:16, ~5s, sound off. Save as `clips/<SHOT>.mp4`.

| Tool | Where | Free allowance (approx., Nov 2026) | Notes |
|---|---|---|---|
| Google Flow (Veo 3.1 Lite) | labs.google/flow | ~50 credits/day, ~10 per clip → about 5 clips/day, 720p | Best realism and physics. First choice for the hook and twist shots. |
| Seedance (Dreamina / CapCut) | dreamina.capcut.com | daily credits; watermark depends on version | Strong motion; check for a watermark before downloading. |
| Kling AI | klingai.com | daily login credits; free exports watermarked | Strong character consistency; queue slow on free tier. |
| PixVerse | pixverse.ai | ~60 signup + ~30 daily credits, 540p, watermark | Native 9:16; backup only (low resolution). |
| Meta AI / Hailuo / Vidu | their sites | small free allowances | Backups when the others are exhausted. |

Tips
- Spread hero shots across tools and days; the hook shot (S01) and the twist shot matter most.
- If a tool watermarks a corner, choose another tool: the 2.5D fallback looks cleaner than a watermark.
- 5s clips are trimmed to the shot length automatically; a 3s shot uses the first 3s.
- Any downloaded format works (mp4/mov/webm); any resolution (it is scaled/cropped to 1080x1920). Prefer 720p or higher.
- Check each tool's terms for commercial use before monetizing.
